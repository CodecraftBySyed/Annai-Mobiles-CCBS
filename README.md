# ANNAI MOBILES - Electronics & Appliances

A premium, modern single-page website for **ANNAI MOBILES** - your trusted destination for genuine smartphones, electronics, home appliances, and accessories in Bargur.

## 🌟 Features
- 📱 **Mobile-First Design**: Fully responsive across all devices
- 🔍 **SEO Optimized**: Structured data, meta tags, sitemap, robots.txt
- ⚡ **High Performance**: Lazy loading, optimized assets, fast load times
- 🛍️ **Product Gallery**: Dynamic products from JSON data sources
- 📍 **Branch Info**: Multiple branch locations & Google Maps integration
- 📱 **Latest Updates**: Instagram-inspired updates section
- 💬 **Contact Form**: WhatsApp & email integration

## 🛠️ Built With
- HTML5
- Tailwind CSS
- Vanilla JavaScript (ES6+)
- JSON for dynamic data
- AOS for smooth animations
- Font Awesome for icons
